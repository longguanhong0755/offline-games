离线网页游戏整合版
==================

启动方法
--------
双击“启动游戏.cmd”。程序会同时打开四个独立页面：
  http://localhost:8766/  （YORG.io 经典版）
  http://localhost:8767/  （YORG.io 3）
  http://localhost:8768/  （Idle Mining Empire，选择普通/创造模式）
  http://localhost:8770/  （Hextris）

游玩结束后，关闭启动后出现的命令窗口即可停止本地服务。

YORG.io 3 模式
--------------
- 生存模式：标准单机玩法，红色水晶与蓝色精华仍然正常消耗。
- 创造模式：红色水晶与蓝色精华都显示为无限，瞬间建造，全部内容解锁。
- 所有已放置建筑和新建筑的升级选项自动解锁。
- 不显示右下角创造模式弹窗。
- 游戏内快捷键：T 跳过一天，P 生成僵尸，H 清除僵尸，J 填满仓库，K 修复全部。
- “皮肤 & 商品店”和“成就”页可正常使用，在线项目已移除。

Idle Mining Empire 离线双模式版
-------------------------------
- 从 http://localhost:8768/ 进入游戏并选择模式。
- 普通模式：10 元开局，现金有限，保留完整经营和离线收益机制。
- 创造模式：同样从零开始，初始没有矿区、经理和额外升级。
  现金和闲置收入显示为无限；购买矿区、雇佣经理、升级设备和解除障碍全部免费。
- 两种模式使用各自独立的本地存档，切换模式不会覆盖另一份进度。
- 广告、统计、账号、支付和在线服务已移除。
- 竖屏或窄屏窗口会自动加边居中，保持原始宽高比，不再压缩画面。
- 不额外显示创造模式面板。

Hextris 离线版
--------------
- 从 http://localhost:8770/ 进入游戏。
- 保留完整单人玩法和本地最高分存档。
- 已移除广告、统计、社交分享、应用商店入口和排行榜上报。
- 不显示广告、分享按钮或额外悬浮面板。

离线说明
--------
- 不需要联网，只使用本机 localhost 静态服务。
- 广告、统计、支付、账号、多人模式、排行榜、模组和社交入口已移除或禁用。
- 存档保存在当前浏览器本地存储中；请固定使用相同端口打开对应游戏。
- 如果浏览器禁用了本地存储/IndexedDB，存档可能无法保存。

运行要求
--------
Windows + Chrome / Edge + Python 3。
第三方脚本、广告和统计已移除；游戏只需本机静态服务。
服务只监听本机，不会向局域网开放。
