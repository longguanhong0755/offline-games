YORG.io 离线整合版
==================

启动方法
--------
双击“启动游戏.cmd”。程序会同时打开两个独立页面：
  http://localhost:8766/  （YORG.io 经典版）
  http://localhost:8767/  （YORG.io 3）

游玩结束后，关闭启动后出现的命令窗口即可停止本地服务。

当前版本
--------
- YORG.io 经典版：2.6.8
- YORG.io 3：1.0.10（提交 a79e8b3c）

YORG.io 3 模式
--------------
- 生存模式：标准单机玩法，红色水晶与蓝色精华仍然正常消耗。
- 创造模式：红色水晶与蓝色精华都显示为无限，瞬间建造，全部内容解锁。
- 所有已放置建筑和新建筑的升级选项自动解锁。
- 不显示右下角创造模式弹窗。
- 游戏内仍可使用快捷键：T 跳过一天，P 生成僵尸，H 清除僵尸，
  J 填满仓库，K 修复全部。
- “皮肤 & 商品店”可正常进入，离线可用的皮肤、地图和难度均显示已解锁，
  皮肤开关会保存在本地；付款、广告、云同步和多人专用条目已隐藏。
- “成就”页面可正常进入，并显示全部成就已解锁。

离线说明
--------
- 不需要联网，只使用本机 localhost 静态服务。
- 广告、统计、支付、账号、多人模式、排行榜、模组和社交入口
  已移除或禁用；本地皮肤与商品页保留并可离线使用。
- YORG.io 经典版主菜单已隐藏后台游戏画布、侧边 HUD 与排行榜残留，
  只保留开始游戏、难度和语言选择；进入游戏后画面正常显示。
- YORG.io 3 的存档保存在当前浏览器的本地存储中；请固定使用
  http://localhost:8767 打开，不要更换端口，否则浏览器会视为另一个站点。
- 经典版使用游戏自身的浏览器本地存档。
- 如果浏览器禁用了本地存储/IndexedDB，存档可能无法保存。

运行要求
--------
Windows + Chrome / Edge + Python 3。
服务只监听本机，不会向局域网开放。
