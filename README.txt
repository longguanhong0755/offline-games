==================

启动方法
--------
双击“启动游戏.cmd”。启动器只启动本地服务并在终端打印地址，不会自动打开大量浏览器标签。
在浏览器中打开需要的地址；关闭启动器终端窗口即可停止服务。

YORG.io 3 模式
--------------
- 生存模式：红色水晶与蓝色精华正常消耗，标准单机玩法。
- 创造模式：两种资源无限、瞬间建造，皮肤/地图/难度/成就/建筑升级全部解锁。
- 创造模式仍从零开局，不预置建筑或额外进度。
- 不显示右下角创造模式悬浮面板。
- 快捷键：T 跳过一天，P 生成僵尸，H 清除僵尸，J 填满仓库，K 修复全部。
- “皮肤 & 商品店”和“成就”页保留本地可用内容，在线项目已移除。

Idle Mining Empire 模式
-----------------------
- 普通模式：10 元开局，现金有限，保留完整经营和离线收益。
- 创造模式：从零开始，现金和闲置收入显示为无限；购买、雇佣、升级和解除障碍免费。
- 两种模式使用独立本地存档，互不覆盖。
- 广告、统计、账号、支付和在线服务已移除。

离线说明
--------
- 不需要联网，只使用 localhost 静态服务。
- 广告、统计、支付、账号、多人、排行榜、云同步和社交入口已移除或禁用。
- 存档保存在浏览器本地存储中；请固定使用相同端口打开对应游戏。
- 服务只监听本机，不会向局域网开放。
- 当前共 19 款游戏，不恢复已占用的 8765 端口。

运行要求
--------
Windows + Chrome / Edge + Python 3。
