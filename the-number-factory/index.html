N 언어 설명서

N은 automatium 프로그램을 위한 미니 언어입니다. 프로그램을 저장한 뒤 왼쪽 목록의 ON 버튼으로 실행합니다. 모든 프로그램은 자동화 틱마다 합계 256개 명령까지만 실행됩니다.

변수와 자료형

변수는 먼저 number 또는 boolean으로 선언한 뒤 값을 대입해야 합니다.

x = number
flag = boolean

x = (get.sp + 10) * 2
flag = get.cp == 0

square와 sp는 현재 가능한 제곱 포인트 수동 교환을 실행합니다. cp는 현재 가능한 수렴 포인트 수동 교환을 실행합니다. 숫자를 붙이면 업그레이드 배율을 포함한 실제 획득량이 그 목표 이상일 때 교환합니다. 교환할 수 없으면 다음 줄로 넘어가며, 끝에 s를 붙인 명령만 조건을 만족할 때까지 현재 프로그램을 대기시킵니다.

kp는 추상화 2-2 연구 후 사용할 수 있습니다. 일반화 8-1과 필수 선행 연구 등 기존 수동 KP 교환 조건을 만족하면 커누스 교환을 실행하고 현재 가능한 KP를 모두 얻습니다. kp 5는 이번 교환 보상이 5 KP 이상일 때만 실행하며, kp (5) s는 조건을 만족할 때까지 대기합니다. 숫자 대신 변수나 계산식을 넣거나, 목표 없이 kp s로 대기할 수도 있습니다. 교환 시 진행 초기화와 추상화 초기화 예약은 기존 커누스와 동일하게 적용됩니다.

조건문

KP 조건은 if get.kp >= 100 { ... }처럼 비교합니다. get.kp는 숫자이므로 단독으로 조건에 넣지 않습니다.

if get.sp >= 1000 and get.cp == 0 {
    buy square_break dyson_swarm
}
elif get.sp >= 16 {
    buy square_break doctor_octopus
}
else {
    square s
}

반복문

while true {
    square s
}

whiletick 20 get.sp < 1000 {
    buy square_break doctor_octopus
}

for 10 {
    square
}

whiletick 20은 조건이 참인 동안 20 자동화 틱마다 본문을 한 번 실행합니다. break는 가장 가까운 while, whiletick, for를 빠져나옵니다. SP와 CP 교환은 각각 sp, cp, 추상화 2-2 이후 KP 교환은 kp 명령으로 자동화할 수 있습니다.

연산자

산술: + - * / % ^ · 비교: == != > >= < <= · 논리: and or not. 괄호도 사용할 수 있습니다. 정수끼리 나누면 소수점 이하는 버립니다. 1e1000처럼 큰 과학적 표기법도 변수, 계산, 비교, SP/CP/KP 목표값에 사용할 수 있습니다.

x = number
x = (2 ^ 10 + 100) * 2

if x >= 2000 and not false {
    square
}
